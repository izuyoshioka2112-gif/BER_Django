## 進め方
モデル+Admin → 商品一覧+カート追加 → カートページ → 席番号入力 → 注文確認(DB保存) → 完了

### 今の制作イメージ
-  自分の席が何卓なのか入力
-  商品一覧ページ:商品ごとに「カートに追加」ボタン(各ボタンが小さいフォーム)
-  カートページ:セッションの中身を表示、数量変更・削除、「注文へ進む」ボタン
-  注文確認ページ:スタッフ選択(ドロップダウン)+「注文する」ボタン → ここで Order/OrderItem をDBに保存、セッションのカートをクリア
-  確認ページ:「ご注文ありがとうございました」→一覧に戻る

### スタッフ側
-  誰が指名されているのか、何を注文して何番卓か、完了したのか
